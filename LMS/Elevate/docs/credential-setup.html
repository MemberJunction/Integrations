Connection setup

Connect your Elevate site

Send us your Elevate site address and an API key for its Report API. Two values, and you are done.

Before you start

Elevate is hosted per organisation, so both values are specific to your own site. There is no shared Elevate host and nothing to sign up for with us.

The API key is issued by whoever administers your Elevate site. If you are not sure who that is, ask your Elevate account contact for a Report API key and point them at this page.

  1. Find your site address

    It is the address you use to sign in to Elevate, without any path after the host — for example https://elevate.your-org.org. We add the rest ourselves.

  2. Get a Report API key

    Ask your Elevate administrator for an API key with access to the Report API. One key covers every report we read; there is nothing to configure per object.

  3. Check what the key can see

    Open <your site>/api/reports in a browser while signed in. That page lists the reports your site exposes, and it is the same list the connector reads. Anything not listed there is not available to us either.

What the connector does with these

Every read is a single POST to <your site>/api/reports, choosing a report by name in the request body and naming the columns it wants. The API key travels in that body, never in a URL, and is never written to a log or an error message.

The connector only reads. It never creates, changes or deletes anything in Elevate.

You're done

Send us these 2 values

Elevate site URL
https://elevate.your-org.org
Report API key
the key your administrator issued
Send the key the way you would send a password, not in an ordinary email. If it is ever exposed, ask your Elevate administrator to issue a new one and send us the replacement.
