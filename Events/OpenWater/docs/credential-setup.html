Connect your OpenWater programs

OpenWater issues API keys to your account on request. There are two of them — collect both and send them to us.

Before you start

You'll need someone who can contact your OpenWater account manager or support. API keys aren't generated from the admin console — OpenWater issues them for you. If your organisation already has keys on file, skip to Step 3.

Step 1 · Ask OpenWater for API keys

Email your OpenWater account manager (or open a support ticket) asking for API keys for a read-only data integration. Ask explicitly for both the API Key and the Client Key — they're two separate values, and requests often come back with only one.

  1. 2

    Check that you received both keys

    OpenWater's API requires two keys sent together. If the reply contains only one, go back and ask for the other by name — the connection cannot authenticate with a single key.

    They're usually labelled API Key and Client Key, though wording varies slightly between accounts.

  2. 3

    Note your organisation code, if you have one

    Some OpenWater accounts are scoped by an organisation code. If OpenWater mentioned one in the same reply, send it along; if they didn't, there's nothing to send and the connection works without it.

You're done

If OpenWater gave you an OrganizationCode, include it — it's optional and only some accounts use one.

Both keys are secrets. Together they read your OpenWater program, application and reviewer data, so send them only to us and only over a secure channel — never in a plain email thread or a shared document.
