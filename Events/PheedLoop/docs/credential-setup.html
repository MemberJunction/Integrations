Connection setup

Connect your PheedLoop organisation

Copy an API key and secret from your PheedLoop organisation settings, note your organisation code, and send us all three. About five minutes.

Self-serve 3 values to send ~5 minutes

Before you start

You'll need an account with organisation-level admin access in PheedLoop — event-level access isn't enough to see the API settings.

Step 1 · Open your PheedLoop organisation settings

https://admin.pheedloop.com

Sign in, then switch to your organisation view rather than an individual event, and open Settings. The API credentials live at the organisation level because they cover every event under it.

  1. 2

    Find the API section

    In the organisation settings, look for API or Integrations. You should see an API Key and an API Secret — or a button to generate them if none exist yet.

    If you don't see this section at all, your account doesn't have organisation-level admin rights; ask whoever administers your PheedLoop account to do this part.

  2. 3

    Copy the key, the secret, and your organisation code

    Copy the API Key and API Secret exactly — trailing spaces from a sloppy selection are a common cause of a connection that mysteriously won't authenticate.

    Your organisation code is the short identifier PheedLoop uses for your organisation; it typically appears in the same settings area and in your PheedLoop URLs.

If the secret was only shown once

Some PheedLoop accounts reveal the secret only at the moment it's generated. If it's now masked and you never copied it, regenerate the pair — just be aware that regenerating invalidates the old pair for anything else already using it.

You're done
