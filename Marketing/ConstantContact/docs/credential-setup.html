Connect your Constant Contact account

Before you start

Sign in at developer.constantcontact.com with your usual Constant Contact username and password — the same login you use to send emails. When you're done you'll have two values to send us: your app's API Key and its App Secret. A final one-click link we email you finishes the connection.

Do this first

Turn on Multi-factor Authentication

Constant Contact now requires MFA on your account before it will let you create an app. In your main Constant Contact account, open your name (top-right) → Settings, find Multi-factor authentication, and click Set Up to enroll (text message, phone call, or authenticator app). If you skip this, the Create button in step 2 fails with “Users must be enrolled in MFA to create applications.”

Constant Contact uses OAuth — a bit more than a single key, but the extra steps are simple. You'll copy two values yourself (the API Key and App Secret), and instead of hand-copying a fiddly third value, we'll send you a one-click authorization link that finishes the connection for you. Follow the steps in order and you'll be done in about ten minutes.

  1. 1

    Sign in to the developer portal

    Go to developer.constantcontact.com and sign in with your usual Constant Contact username and password. Once you're in, open the My Applications tab.

  2. 2

    Create a new application

    Click New Application. Give it a name you'll recognize — for example “MemberJunction” (this is the name you'll see later on the approval screen). For the OAuth2 method choose Authorization Code Flow, and for the refresh token method choose Long Lived Refresh Tokens (simplest — Rotating Refresh Tokens also work). Then click Create.

  3. 3

    Open your app and copy the API Key

    Back on My Applications, click edit next to your new app. In the default Details view you'll see the API Key — copy it. That's the first of the two values we need.

  4. 4

    Generate the App Secret

    On the same page, click Generate Client Secret. Constant Contact shows the secret only once, so copy it right away and keep it somewhere safe. Then click Save. That App Secret is the second value we need.

  5. 5

    Add the redirect URL we give you

    Find the Redirect URI field in your app settings and paste in the exact URL from your setup email: https://<the redirect URL MemberJunction gives you>. Leave the flow set to Authorization Code Flow, then click Save. This tells Constant Contact it's safe to hand the connection back to us.

  6. 6

    Finish with the one-click authorization link

    The last step is a single click on your end. We'll email you a one-click authorization link. Open it, sign in to Constant Contact if you're asked, and you'll see a Permission Request screen showing “MemberJunction” and the read access it's requesting — click Allow. That completes the connection and issues your refresh token automatically. You won't need to do this again unless you revoke access.

You're done

The Refresh Token is handled by the authorization link — it's created for you when you open the one-click link we send, so there's nothing to copy for that one. Once connected, MemberJunction keeps the rotating token fresh automatically.

Treat the App Secret like a password. Together with the API Key it grants read access to your Constant Contact data, so share these only with us over a secure channel. Remember the secret is shown only once — and you can revoke access any time by deleting the application from My Applications.
