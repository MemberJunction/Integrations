Connection setup

Connect your NetSuite account

Create a read-only integration record and an access token in NetSuite, then send us the five values they produce. About fifteen minutes for a NetSuite administrator.

Administrator required 5 values to send ~15 minutes

Before you start

You'll need a NetSuite administrator — creating integration records and access tokens is an admin-only action. Two of the five values are shown exactly once, at the moment you create them, so have somewhere safe to paste them before you start.

Step 1 · Sign in to NetSuite as an administrator

https://.app.netsuite.com

Replace <your-account-id> with your own account number — it's the same one that appears in the address bar whenever you're using NetSuite. Sandbox accounts look like 1234567_SB1.

  1. 2

    Turn on Token-Based Authentication

    Go to Setup → Company → Enable Features, open the SuiteCloud tab, and make sure Token-Based Authentication is ticked. Save if you had to change it.

    If it's already on, nothing to do — move to the next step.

  2. 3

    Create the integration record

    Go to Setup → Integration → Manage Integrations → New. Give it a name you'll recognise later, such as MemberJunction Sync, and tick Token-Based Authentication.

    When you save, NetSuite shows a Consumer Key and a Consumer Secret — this is the only time it ever shows them. Copy both now.

  3. 4

    Create the access token

    Go to Setup → Users/Roles → Access Tokens → New. Pick the integration you just created, pick the user the sync should run as, and pick a role that can read the records you want synced — a read-only role is ideal.

    Saving shows a Token ID and a Token Secret, again only once. Copy both.

  4. 5

    Note your account ID

    It's the number in your NetSuite address — for example 1234567, or 1234567_SB1 for a sandbox. Send it exactly as it appears, including the sandbox suffix if there is one.

If you missed a secret

Consumer secrets and token secrets genuinely cannot be re-displayed. If a value scrolled past before you copied it, delete that integration record or access token and create a fresh one — it takes a minute and nothing else is affected.

You're done

All four key and token values together grant access to your NetSuite data — the role you picked in Step 4 is what limits what they can reach, which is why a read-only role is worth the extra minute. Send them only to us and only over a secure channel.
