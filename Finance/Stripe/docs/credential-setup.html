Before you start

You'll need access to your organization's Stripe dashboard. When you're done you'll have one value to send us: your Test-mode Secret key (it starts with sk_test_).

Step 1 · Open this page

https://dashboard.stripe.com/test/apikeys

Paste it straight into your browser's address bar. The /test/ in the link lands you on your test keys automatically — no toggles to hunt for.

  1. 2

    Copy your Secret key

    On that page, scroll to Standard keys and find the Secret key row (boxed below). Click it to reveal the value, then use the copy icon. That single sk_test_… string is all we need.

Shortcut

Already on your Stripe Home dashboard? The same key sits in the API keys panel on the right — copy it straight from there, no navigating required.

You're done

Send us this one value

sk_test_•••••••••••••••••••••••• Stripe

Treat this key like a password. Anyone with it can read your Stripe data, so share it only with us and only over a secure channel. It's a test-mode key, so it can never touch real payments — but it's still worth protecting.
