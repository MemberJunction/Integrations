Before you start

Sign in to Salesforce as a System Administrator (or any user who can open Setup and manage apps). Your org also needs My Domain turned on — nearly every org already has it. When you're done you'll have three values to send us: the Consumer Key, the Consumer Secret, and your My Domain URL.

Salesforce is gradually renaming its developer tools, so newer orgs may nudge you toward “New External Client App” instead of the classic “New Connected App.” Don't let that throw you — the steps below use the App Manager → New Connected App path, which still works in every org today. If your org only offers External Client App, the same OAuth settings live there under a slightly different layout.

  1. 1

    Find your My Domain URL

    Click the gear Setup (top-right), and in the Quick Find box type My Domain. Copy your Current My Domain URL — it looks like https://yourorg.my.salesforce.com. This is one of the three values, and it matters: MemberJunction talks to Salesforce at your address, not the generic login page.

  2. 2

    Open App Manager and start a new app

    Still in Setup, type App Manager in Quick Find and open it. Click New Connected App (top-right). If your org shows New External Client App instead, that's fine — choose it and follow the same OAuth settings below.

  3. 3

    Fill in the basic information

    Give the app a Connected App Name you'll recognize later — for example “MemberJunction.” The API Name fills in automatically, and add your Contact Email. A logo and description are optional.

  4. 4

    Turn on OAuth and add a Callback URL

    Scroll to API (Enable OAuth Settings) and tick Enable OAuth Settings. In Callback URL, paste https://login.salesforce.com/services/oauth2/callback. Salesforce requires a callback URL even though this server-to-server connection never uses it, so any valid https address is fine.

  5. 5

    Add the OAuth scopes

    Under Selected OAuth Scopes, add the two scopes below. They let MemberJunction read your records through the API — we only pull data, we never change anything in Salesforce.

    Move each of these into Selected OAuth Scopes:

    • Manage user data via APIs (api)
    • Perform requests at any time (refresh_token, offline_access)
  6. 6

    Enable the Client Credentials Flow, then Save

    Still in the OAuth section, tick Enable Client Credentials Flow and confirm the notice. Then click Save at the top. Salesforce may take a few minutes (up to about ten) to finish setting the app up — that's normal.

  7. 7

    Set the Run-As user (required)

    Open the app again and click Manage, then Edit Policies. Under Client Credentials Flow, choose a Run As user — an integration or admin user whose data we should read — and Save. Don't skip this: without a Run-As user the connection can't get a token and the sync will fail.

  8. 8

    Copy the Consumer Key and Secret

    Back on the app page, in API (Enable OAuth Settings) click Manage Consumer Details. Salesforce emails you a verification code — enter it, then copy the Consumer Key and Consumer Secret. Those two values, plus your My Domain URL, are everything we need.

You're done
