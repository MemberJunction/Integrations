Before you start

Sign in to HubSpot as a user with Super Admin permission (the account owner has this by default). When you're done you'll have one value to send us: the private app's access token.

HubSpot is mid-way through reorganizing its developer tools, so along the way you'll see the words “Legacy Apps” and a nudge toward “Service Keys.” Don't let that throw you — the steps below are the current, working path to the token we need. When HubSpot asks, keep choosing the private app.

  1. 1

    Open Private Apps in Settings

    Click the gear Settings (top-right), then in the left sidebar open Integrations and choose Private Apps. (If your account only shows Legacy Apps under Integrations, that link gets you to the same place.)

  2. 2

    Create the app, and choose Private

    Click Create (it may read Create legacy app). When HubSpot asks what kind, pick Private — “For one account.”

  3. 3

    Continue past the “Service Keys” suggestion

    HubSpot will suggest Service Keys as a “better path.” For MemberJunction we want the private app, so tick “I understand…” and click Continue with legacy private app.

  4. 4

    Name your app

    On the Basic Info tab, give it a Name so you'll recognize it later — for example “MemberJunction.” A logo and description are optional.

  5. 5

    Add the read scopes, then Create app

    Open the Scopes tab and add these read scopes (they let us pull your records — nothing is ever changed). Then click Create app at the top-right and confirm.

    Use Add new scope and search for each of these:

    • crm.objects.contacts.read
    • crm.objects.companies.read
    • crm.objects.deals.read
    • crm.objects.owners.read
    • crm.objects.line_items.read
    • crm.objects.products.read
    • crm.lists.read
    • crm.schemas.contacts.read
    • crm.schemas.companies.read
    • crm.schemas.deals.read
  6. 6

    Open the Auth tab and copy the token

    Your app is created. Open the Auth tab, click Show token, and copy the Access token. That single value is what we need.

You're done
